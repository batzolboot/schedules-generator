## Mapping status

Phase 3B inspected a minimal authorized, sanitized sample. The current public
entry still redirects to Drexel Connect, but the fields marked **Confirmed**
below were observed in the saved Summer Quarter 25-26 fixtures.

Each mapping is labeled:

- **Confirmed**: visible in accessible public HTML.
- **Expected**: required by the product and database, but not yet confirmed in current WebTMS HTML.
- **Derived**: intended to be normalized or calculated by the future parser/importer.

## Cross-listing

Cross-listing is unconfirmed and has no dedicated MVP table. Until fixtures establish semantics:

- preserve each displayed course and section identity independently;
- retain a source cross-list label in parsed metadata if present;
- do not merge records based only on matching instructor, time, or location;
- propose a schema revision before persisting formal cross-list relationships.

## Proposed client interface

The client is responsible only for respectful HTTP retrieval. It does not parse or persist.

```python
class WebTMSClient(Protocol):
    def fetch(self, url: str, *, referer: str | None = None) -> FetchedPage: ...

@dataclass(frozen=True)
class FetchedPage:
    url: str
    final_url: str
    status_code: int
    retrieved_at: datetime
    content: bytes
    content_type: str | None
```

Required implementation policies:

- descriptive user agent;
- allowlisted Drexel HTTPS hosts;
- bounded redirects and timeouts;
- minimum delay between live requests;
- optional in-memory/on-disk response reuse during one explicit run;
- no authentication, CAPTCHA handling, or access-control circumvention;
- no database dependency.

The authenticated client implements these discovered routes while retaining one browser context. It strips query strings from logs, not from actual navigation.

## Proposed parser interface

The parser accepts supplied HTML and source context. It performs no HTTP and no database writes.

```python
class WebTMSParser(Protocol):
    def parse_terms(self, html: str, *, source_url: str) -> tuple[ParsedTerm, ...]: ...
    def parse_navigation(
        self, html: str, *, term: ParsedTerm, source_url: str
    ) -> tuple[ParsedNavigationItem, ...]: ...
    def parse_course_page(
        self, html: str, *, term: ParsedTerm, source_url: str
    ) -> ParsedCoursePage: ...
```

Parsing should return immutable source-domain records, not SQLAlchemy models.

## Proposed parsed records

```python
@dataclass(frozen=True)
class ParsedTerm:
    source_identifier: str
    name: str
    calendar_type: Literal["quarter", "semester", "unknown"]
    start_date: date | None
    end_date: date | None
    last_updated_at: datetime | None
    detail_url: str

@dataclass(frozen=True)
class ParsedCourse:
    source_identifier: str | None
    subject_code: str
    subject_name: str | None
    course_number: str
    title: str
    minimum_credits: Decimal | None
    maximum_credits: Decimal | None
    college_name: str | None
    department_name: str | None

@dataclass(frozen=True)
class ParsedSection:
    source_identifier: str | None
    crn: str | None
    section_code: str
    component_code: str
    component_name: str | None
    instruction_method: str | None
    campus: str | None
    status: Literal["active", "canceled", "closed", "unknown"]
    cross_list_identifier: str | None
    instructors: tuple[ParsedInstructor, ...]
    meetings: tuple[ParsedMeeting, ...]

@dataclass(frozen=True)
class ParsedInstructor:
    source_identifier: str | None
    display_name: str
    is_primary: bool
    display_order: int

@dataclass(frozen=True)
class ParsedMeeting:
    source_identifier: str | None
    meeting_type: str
    days_of_week: tuple[int, ...]
    start_date: date | None
    end_date: date | None
    start_time: time | None
    end_time: time | None
    building: str | None
    room: str | None
    location_text: str | None
    is_asynchronous: bool
    is_arranged: bool

@dataclass(frozen=True)
class ParsedCompatibilityRule:
    source_section_key: str
    target_component_code: str
    allowed_target_section_keys: tuple[str, ...]
    is_authoritative: bool

@dataclass(frozen=True)
class ParsedCoursePage:
    course: ParsedCourse
    sections: tuple[ParsedSection, ...]
    compatibility_rules: tuple[ParsedCompatibilityRule, ...]
    warnings: tuple[str, ...]
```

Fields that cannot be proven from source HTML should remain `None`, `unknown`, or emit a parsing warning. The parser must not fabricate dates, times, component requirements, identifiers, or compatibility.

## Phase 4 crawler decisions

- `Max Enroll` maps to nullable, nonnegative `sections.maximum_enrollment`.
- Final-exam rows are recognized and counted but excluded from regular
  `meeting_times`; they therefore never become weekly calendar blocks.
- Live term code `202615` was verified for `Fall Quarter 26-27` on August 2,
  2026. The refresh command still discovers and matches the term name live
  rather than hard-coding that code.
